#   Letter Sorter

A [TTU Whitacre College of Engineering](https://www.depts.ttu.edu/coe/) ECE-3332 Microcontrollers project
 <img src = 'Images/dbl_T.png'/>

## Description

The Letter Sorter system autonomously sorts letters in 4 region boxes approximating a distributor to regional post offices.
### Dependencies
#### OCR Model Cloud Deploymnet 
* OpenCV
* Fastapi
* Pillow
* Numpy
* Regex
* PaddleOCR
* paddlepaddle

#### Master controller
* Requests
* OpenCV
* Threading
* Serial
